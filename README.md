# Students_Attendance_Management_System
Developed a web-based Student Attendance Management System using HTML, CSS and JavaScript.

Key Features:

- Automatically displays the current date.
- The date cannot be manually changed, helping maintain accurate attendance records.
- Attendance can be updated only before 6:00 PM.
- After 6:00 PM, the attendance record cannot be updated for that day.
- Provides a simple and user-friendly interface for managing student attendance.
- Deployed the project online for easy access.
